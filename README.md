## Установка навыков

Скопируйте нужную папку целиком из `skills/` в `~/.codex/skills/`. В запросе укажите `$имя-навыка` и задачу. Для обнаружения новых навыков текущему приложению может потребоваться новый чат.

Пример:

```text
Используй $afabrik-kitchen-projecting. Подготовь ТЗ и дизайн кухни в SketchUp по обмерам. Пока без чертежей.
```
