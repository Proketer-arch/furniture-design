# База проектирования мебели AFABRIK

Версия: 2026-10-15. Основание: пять предоставленных DOCX, обозначенных S1–S5 в [реестре источников](source-texts.md). Это рабочий профиль по документам пользователя, не универсальный стандарт мебели и не проверенный каталог производителя.

## Как читать требования

- **Исходное требование** — значение прямо записано в DOCX; его область применения сохраняется.
- **Вариант** — нужно выбрать для конкретного заказа; перечень не означает одновременное применение.
- **Уточнить** — запись неоднозначна/противоречива, значение не назначается автоматически.
- **Дополнение процесса** — контроль, добавленный при подготовке инструкций; он не приписывается автору DOCX.

Для каждого параметра хранить значение, единицу, источник, статус и редакцию. Пустое поле не равно нулю; диапазон не означает выбранную толщину. До выбора значения допустима предварительная модель с явно обозначенными допущениями. Выпуск обработки/производственной документации требует закрытия влияющих на него вопросов.

## 6. Общие исходные данные

Кухня: помещение в мм, окна/двери и открывание, точки воды/слива/электрики/газа/вентиляции/котла, стены/ниши/углы/плинтусы; функциональные зоны, техника, планировка, материалы, фурнитура, свет, эргономика/детские ограничения (S5-P004–P055).

Шкаф: фотографии и замер, плинтус ширина/высота, счётчик/трубы/котёл при наличии, габариты шкафа, видимые бока, двери и свет (S3-P002–P018), затем конструкция/комплектация S4.

## 7. Дополнения процесса

Эти действия добавлены при систематизации, не являются цитатами из DOCX:

- Разделять стадии: бриф → предварительная модель → проверенная конструкция → производственный выпуск.
- Вести реестр допущений и вопросы [C01–C12](clarifications.md); решение по одному проекту не становится универсальным стандартом.
- Для фурнитуры выбирать систему/артикул/комплект/документ. Предпочитаемые пользователем поставщики МДМ/КДМ/МАКМАРТ — контекст беседы, не сведения пяти DOCX. Цены/наличие проверяются при соответствующей задаче.
- Неполный бриф позволяет концепцию, но не подтверждает сверление, ЧПУ или монтажную готовность. «Не обязательно» для производителя на старте не отменяет выбора системы перед присадкой.
- Работа в SketchUp/БАЗИС требует реального доступа и проверки native-результата. Документы не задают лицензии, меню, API или разрешение на изменение клиентских моделей.
