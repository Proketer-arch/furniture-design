# Отдельный интерьерный альбом

## 1. Состав по стадии

Рабочий состав согласуется по объекту, обмеру, конструкциям и поручению. Не создавай фиктивные разделы инженерного проекта из условной расстановки оборудования.

| Раздел | Что должен сообщать |
|---|---|
| Титул / ведомость / общие данные | Проект, стадия, состав, источники, легенда, нулевая отметка, ограничения |
| Обмерный план | Подтверждённые размеры, высоты, проёмы, выступы, коммуникации/неизвестные |
| Демонтаж / монтаж | Существующее/удаляемое/новое, привязки, типы и ссылки на согласованные решения |
| План мебели | ID изделий, габариты, открывания, проходы, привязки и ссылки на мебельный альбом |
| План пола | Покрытия, границы, раскладка/начало, уровни и узлы сопряжений |
| План потолка | Типы/высоты, уровни, ниши, люки, карнизы, световые элементы |
| Свет / выключатели / розетки | ID, высоты/привязки, сценарии и задания смежникам в пределах имеющихся данных |
| Сантехника / оборудование | Модели/габариты/подключения по подтверждённым паспортам, зоны доступа |
| Развёртки стен | Номер помещения/стены, отделка, мебель, отверстия/приборы, отметки и узлы |
| Разрезы и узлы | Высотные цепи, слои, сопряжения, привязки к конкретным местам |
| Экспликации / ведомости | Помещения, отделка, двери, оборудование/свет/мебель по необходимому составу |

Этот список — меню разделов, не нормативная обязательность и не подтверждение инженерных расчётов. На ранней стадии укажи концептуальные/предварительные данные. Электрические группы, нагрузки, сечения проводов, вентиляционные расходы и несущие решения не назначаются чертёжником без подтверждённого проекта соответствующей дисциплины.

## 2. План и базовая геометрия

Обмерная геометрия и чистовые размеры должны быть различимы. Укажи, что взято по факту, из исходного проекта или предположено. Не распределяй невязку обмера незаметно; заведи вопрос по конкретной стене/диагонали.

Фиксируй `room_id`, стены, проёмы, высоты, базовые оси/точки, направления взгляда. Единицы размеров и отметок явно согласованы. Нулевую отметку сопоставь с объектом: чистый пол помещения, исходный пол или иной установленный datum. Не переноси один ±0.000 между разными источниками без связи.

Секущий план выбирай по задаче: он должен показывать нужные проёмы и элементы. При необходимости используй несколько сечений/отдельные вставки. Не называй изображение сверху планом сечения, если оно показывает крыши/верхние поверхности вместо нужных элементов.

## 3. Развёртки стен

На плане поставь указатели стен/направления взгляда. Введи понятный порядок, например по часовой стрелке от определённой стены; это соглашение проекта. Для каждой стены камера смотрит из помещения на стену, левая/правая сторона проверены по проёмам и соседним стенам.

Развёртка включает: ширину/высоту, проёмы, чистовые уровни, отделку/границы, плитку/панели/швы, встроенную мебель, приборы/розетки, ниши/карнизы и ID узлов. Привязки давай к проверенной базе, а не к условному краю картинки.

Четыре стены можно разместить на одном листе при читаемости; сложные стены выноси отдельно. Сохраняй один масштаб для сопоставимых развёрток либо подписывай каждый. Не растягивай узкую стену для одинаковой ширины изображения.

Развёртка с суммарной длиной по периметру допустима как схема, но подпиши сгибы/углы и не подменяй ею независимые ортогональные виды при сложной геометрии. Криволинейная стена требует определённого способа проекции/развёртывания; ортографический вид не даёт автоматически длину по поверхности.

## 4. Узлы и согласование

Отметь место узла на плане/развёртке, обозначение, лист назначения и масштаб. Узел показывает реальные толщины и границы материалов, крепление, зазор и порядок сопряжения по утверждённому решению. Декоративная линия не подтверждает технически осуществимое крепление.

В кухне/санузле сверяй мебель, столешницу, технику, проёмы, розетки, слив/воду, люки и зоны обслуживания. Для каждой дисциплины сохраняй источник и статус согласования. После изменения мебели проверь интерьерные привязки; не обещай полное согласование смежников по одному плану.

## 5. Таблицы

Экспликация: ID, название, площадь, метод/контур измерения, высота при необходимости, примечание. Ведомость отделки — поверхность, материал/код, количество, единица, основание измерения и ссылка на вид/узел. Статус уточнения виден.

Площадь пола, отделки стен, потолка и закупочное количество не взаимозаменяемы. Вычеты проёмов, откосы, ниши, запасы и упаковки учитываются по определённой методике. Формулы и поля — в [schedules-and-data.md](schedules-and-data.md).

## 6. Приёмка

По каждому помещению проверь: план → указатели стен → все нужные развёртки → отделка/оборудование → таблицы → узлы. ID комнаты и мебели одинаковы в обоих альбомах. Нет стены с одним названием на плане и другим в ведомости; мебельный альбом не содержит иной габарит той же кухни.
