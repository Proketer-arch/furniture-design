# Проверка альбомов и выпуск

## Критерии до работы

Определи состав каждого альбома, формат/масштаб, необходимые виды/размеры/таблицы, нормативный профиль, исходники и статус данных. Для простой правки проверяй изменённый лист и затронутые зависимости; для выпуска — все передаваемые страницы.

## Матрица приёмки

| Объект | Проверка |
|---|---|
| SKP/таблицы | Путь, редакция, сохранение, сцены, ID, данные |
| .layout | Открывается, links доступны, состав/слои/страницы соответствуют |
| Виды | Верная сцена/камера/сечение, полный кадр, scale, overrides |
| Размеры | Базы, ассоциации, units, значения, отсутствие ложных overrides |
| Таблицы | Количество/ID/единицы/диапазоны/полнота/читаемость |
| Штампы | Обозначения/номер/итог/title/редакция/нефиктивные роли |
| PDF | Все страницы, формат, масштаб, шрифты, линии, обрезка |
| DWG/DXF при задании | Единицы, геометрия/аннотации, слои и открытие в целевом CAD |
| Два альбома | Общие IDs/габариты/материалы, актуальные взаимные ссылки |

Наличие двух файлов не доказывает совпадение их редакций. PDF, открытый только на первой странице, не считается полным визуальным QA.

## PDF и печать

Экспортируй каждый альбом отдельно в согласованном составе и настройках. Открой экспорт, проверь количество и порядок страниц, физические размеры, ориентацию, кириллицу и шрифты, тонкие линии/штриховки, прозрачность/заливки, размеры/таблицы, растровые фрагменты и рамку.

Читаемость проверяй при масштабе печати, а также увеличением для артефактов. Контрольная длина модели L на ортографическом виде 1:n должна быть L/n mm на PDF при выводе 100%. Не считай это проверенным по одному видимому размерному числу: нужен фактический масштаб геометрии.

Если PDF-инструменты доступны, получи MediaBox/pages/fonts и отрендерь каждую страницу; визуально просматривай изображения. Извлечённый текст не доказывает читаемость/расположение. Не устанавливай тяжёлые зависимости, если доступны bundled runtime или уже установленные средства.

Для A3 landscape ожидаемый физический размер 420×297 mm, PDF размер в points около 1190,55×841,89. Это проверка формата страницы, не нормы полей/штампа. Пробная печать/измерение возможна только при доступном принтере и соответствующей задаче; не объявляй её выполненной по PDF.

## DWG/DXF

Экспорт по просьбе/требованию получателя. Проверь установленную версию LayOut, настройки model space/paper space, единицы, слой видимости/служебных элементов, аннотации и геометрию. Возможности DWG менялись между 2025/2026 — не обещай новые функции на старой версии.

Сравни минимум один известный размер и состав после открытия в принимающем CAD. Векторный экспорт вида не native-мебельная модель с обработкой; PDF/DWG не являются ЧПУ-программой. Не заявляй проверку в целевом CAD, если файл только создан.

## Изменения и передача

Реестр: `album_id | revision | source_revision | sheet_id | change | reason | affected_dependencies | status | check`.

Изменение ширины шкафа затрагивает мебельные виды/детали/спецификацию и интерьерный план/развёртку/привязки. Исправление орфографии не требует нового полного обмера. Глубину QA выбирай по последствиям.

Не удаляй старую редакцию молча и не оставляй новые данные под старым обозначением выпуска. Подпиши предварительный/рабочий статус. Облако/отправка адресату — отдельные действия в разрешённом объёме, не следствие сохранения PDF.

Комплект передачи: интерьер.layout/PDF, мебель.layout/PDF, необходимые связанные SKP/CSV/XLSX, реестр листов/изменений и список открытых вопросов. Перед передачей проверь переносимость ссылок на выбранном рабочем месте; абсолютный путь на твоём компьютере не гарантирует переносимость. Native `.layout` не гарантирует наличие нужных шрифтов у получателя.

## Диагностика

| Симптом | Что отличить и проверить |
|---|---|
| Вид устарел | Сохранён ли SKP, тот ли reference, render/update, сцена/override |
| Размер неверен | Модель/лист, units/scale, точка привязки, ручной override, перспектива |
| Развёртка зеркальная | Направление взгляда, положение камеры/проёма, трансформация |
| Масштаб съехал | Perspective/Ortho, resize/Preserve Scale, печать Fit, PDF page size |
| Часть модели исчезла | Видимость/сечение, clipping mask, камера/контекст, область кадра |
| Таблица теряет строку | Source/range, split, сортировка, локальное изменение/reference |
| PDF линии/текст пропали | Рендер, шрифты, прозрачность/заливка, экспорт/качество |
| Таймаут | Наличие/читаемость файлов и статус процесса до повтора |

Сначала минимальный различающий тест/копия, затем исправление причины и проверка затронутого результата. Не рестартуй приложение с несохранённой работой ради предположительной ошибки.

## Отчёт

Укажи фактические файлы/редакции, что проверено, где источник недоступен/параметр не подтверждён, какие листы предварительные. Полное нормативное соответствие, согласование клиента и готовность к изготовлению сообщаются только при соответствующих доказательствах.
