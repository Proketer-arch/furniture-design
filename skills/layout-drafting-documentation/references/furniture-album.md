# Отдельный мебельный альбом

## 1. Назначение и состав

Установи стадию: согласование внешнего вида, рабочая конструкция, изготовление, сборка или монтаж. Презентационный альбом может показывать материалы/габариты; производственная КД требует проверенных деталей, обработки и комплектности.

| Лист / документ | Содержание |
|---|---|
| Титул, ведомость, общие требования | Проект, изделие, стадия, обозначения, источники и редакции |
| Общий/габаритный вид | Габариты, фасадные деления, материалы, назначение, связи с интерьером |
| Сборочный чертёж | Состав, позиции, установочные размеры, соединения, разрезы и примечания |
| Фасады / внутреннее наполнение | Зазоры, открывания, полки/ящики, зоны механизмов и реальные размеры |
| Разрезы / узлы | Толщины, задники, паз/четверть, цоколь, столешница, крепёж/механизмы |
| Детальные чертежи | Контуры, базы, толщины, материал, кромки, присадка и сложная обработка |
| Спецификация | Детали/сборки/покупные изделия по установленной системе |
| Монтаж | Привязки к объекту, крепления, доступ, регулировка, зазоры и очередность |
| Схема сборки / взрыв-схема | Порядок и ориентация, дополнение к однозначной КД |

Состав выбирай по сложности: не плодить одинаковые виды, но не прятать отсутствующие данные за аксонометрией. Развёртка фасадов мебели не заменяет детали дверей/панелей и присадку.

## 2. ID и разделение типов документов

Назначь ID изделия/сборки/детали и позиции спецификации. Не используй номер строки как устойчивый ID при сортировке. Одинаковые детали имеют одинаковый ID только при совпадении всех существенных характеристик: материал, толщина, контур, кромки, обработка, зеркальность, отделка и редакция.

Не смешивай общий вид, сборочный, монтажный и детальный чертёж. Код/обозначение выбирается по нормативному профилю и системе предприятия, не по случайным буквам. `FUR-F01` — допустимое учебное соглашение, не утверждённый ЕСКД-классификатор.

Габарит изделия, монтажный проём, размер фасада, чистовой размер детали и заготовка должны иметь названия/контекст. Не передавай заготовку в изготовление с подписью чистового размера.

## 3. Изображения

Главный вид выбирай по конструкции/назначению. Добавь сверху/сбоку/сзади только если они раскрывают нужные данные. Согласуй проекционный метод и расположение видов с нормативным профилем; не зеркаль вид ради композиции.

Разрезы показывают скрытые соединения/профили. Для сложного механизма используй документацию производителя с артикулом/версией. Взрыв-схема помогает сборке, но сдвинутые детали нельзя размерить как фактические монтажные расстояния.

Рендер/перспективу маркируй как иллюстрацию, если рядом есть размерные виды. Для наклонного фасада/панели используй дополнительный вид перпендикулярно поверхности либо истинную форму, а не укороченную проекцию как размер детали.

## 4. Детальный чертёж панели

Карточка: ID/название/qty/материал/толщина/единицы/редакция; обозначение главной пласти и текстуры; локальные базы X/Y; контур; кромки по конкретным сторонам; отверстия/пазы/вырезы; глубины/диаметры; обратная сторона и переворот при необходимости; допуски/требования по подтверждённой технологии.

Для глухого отверстия укажи сторону входа и глубину, для сквозного — соответствующее обозначение по принятому профилю. Одинаковая проекция отверстия не подтверждает одинаковую сторону обработки. Не придумывай глубину из внешнего вида крепежа.

Кромки и компенсации согласуй с конструктором/технологом. Укажи, что размер изображает: основу, чистовой габарит или раскройную заготовку. Двойная поправка кромки при передаче в БАЗИС/раскрой недопустима.

2D обозначения обработки в LayOut сверяются с реестром операций; они не создают ЧПУ-программу. При наличии данных БАЗИС сверяй IDs, версии и базы, а не обводи картинку как доказательство геометрии.

## 5. Спецификация и закупка

Выноски позиций соответствуют спецификации; qty учитывает экземпляры, вложенные сборки и комплекты. Установи, нормированы количества на одно изделие или весь заказ. Артикул производителя, поставщика, монтажный крепёж, ответные части и состав системы различимы.

Материалы/фасады/кромки/фурнитура/комплекты/упаковка имеют свои единицы. Метры кромки не становятся штуками; комплект петли не обязательно включает монтажную планку. Для подбора/цен пользователь использует МДМ, КДМ, МАКМАРТ; цены проверяются при конкретной закупочной задаче, не включаются в КД как вечные данные.

Экспликация изделий для интерьера — краткая таблица ID/габаритов/материалов; производственная спецификация — состав изделия. Свяжи их, но не подменяй одну другой.

## 6. Монтаж и выпуск

Монтажные виды показывают datum объекта, чистовые размеры, установочные зазоры, стены/основание, анкеровку по подтверждённому решению, регулировку и доступ. Точки крепления и несущая способность требуют исходных данных, а не угадывания оформителя.

Проверка: позиции↔спецификация; фасад↔наполнение; деталь↔сборка; кромка↔размер; отверстия↔фурнитура; изделие↔обмер/интерьер. Закрытие оформления не доказывает прочность, технологичность или готовность к производству без этих проверок.
