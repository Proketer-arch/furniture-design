# Спецификация двух шаблонов LayOut

Рабочая спецификация для создания native-шаблонов при доступе к программе. Этот файл — не `.layout` и не нормативная форма.

Для AFABRIK учитывать [пользовательский профиль](../references/afabrik-drafting-profile.md). Его рабочие настройки не заменяют проверку выбранной нормативной формы.

## Общие поля

project_id; album_id; designation; project_name; object/address; client; stage; revision; source_revision; date; organization; prepared_by; checked_by; approved_by; sheet_number; sheet_total; sheet_title; view_scale; change_register.

Неизвестные значения остаются незаполненными/отмеченными по правилу проекта. Поля проверки/утверждения не заполняются вымышленными действиями. Набор реквизитов и геометрия нормативного штампа выбираются по применимому полному тексту.

## Интерьерный шаблон

Рекомендуемый старт A3 landscape 420×297 mm, допустим другой согласованный формат. Общие слои: рамка/штамп/общие реквизиты. Слои страницы: виды, размеры, выноски, таблицы, изменения. Служебная графика должна быть исключена из конечной выдачи проверенным способом.

Типы страниц: титул; ведомость/легенда; план; развёртки помещения; разрез/узлы; таблицы. Не задавай фиксированное число страниц: оно зависит от проекта. Подготовь зоны для одного крупного плана, нескольких развёрток и крупного узла, не уменьшая масштаб молча.

Для стартовой компоновки можно пробовать 1:50/1:25 для комнаты и 1:10/1:5 для узлов; это варианты, не утверждённый нормативный ряд. В нормативном профиле проверь допустимые значения.

## Мебельный шаблон

Рекомендуемый старт A3 для сборки и A4/A3 для деталей, после проверки доступного формата/печати. Если установленная версия не поддерживает нужные разные форматы в одном документе, используй единый формат или согласованные отдельные документы; не обещай такую возможность без проверки.

Типы страниц: титул/ведомость; общий/сборочный; наполнение/разрезы; детали; спецификация; монтаж/сборка. На детальном листе зарезервируй материал/толщину, qty, ID, базы пласти и место для таблицы обработки. Для нескольких масштабов — подписи под каждым видом.

## Библиотека элементов

Создай проверенные группы: знак направления развёртки; указатель разреза/узла; позиционная выноска; отметка; направление текстуры; условные материалы; таблицы; рамка/штамп нужного профиля. Графика/размеры берутся из применимого нормативного текста, не из рисунка этого файла.

## Приёмка native-шаблонов

Сохранить → открыть заново → вставить тестовую модель/таблицу → проверить Auto-Text/уникальные поля/слои → создать вторую страницу → убедиться, что уникальный title не скопирован на все листы → экспортировать PDF → проверить формат/масштаб/шрифты/видимость. Файл можно считать готовым шаблоном только после этого.
