# 08. Остров и полуостров

Правила: [R-ISL-01…06](rules-catalog.md), планировка — [R-LAY-06](rules-catalog.md). Источники — зарубежные и российские дизайнерские ориентиры и NKBA (Р, Н); значений прочности и свеса нет (D-11). Расхождения источников разрешены в X-01 и X-15.

## 1. Проходы вокруг острова (R-ISL-01)

| Параметр | Значение, мм | Основание |
|---|---|---|
| Минимум между островом и рядом | 1000 | политика базы (X-01, Q-06) |
| Рекомендуется | 1100–1200 | IS-01, IS-04 |
| Только по явному подтверждению владельца | 900 | IS-04 |
| NKBA, один работающий | 1067 (42″) | IS-02 |
| NKBA, двое работающих | 1219 (48″) | IS-02 |

Проход мерить между фасадами **с ручками** и с открытыми дверцами техники (ПММ, духовка). Для стороны посадки отсчёт идёт от края свеса — это инженерное допущение, источники явного значения не дают; подтверждается заказом (Q-06).

## 2. Размеры острова (R-ISL-02)

| Параметр | Значение | Источник |
|---|---|---|
| Глубина острова с рабочей функцией | не менее 800 | IS-01 (X-15: IS-05 допускает 600–800) |
| Длина без посадки | не менее 1200 | IS-05 |
| Длина рекомендуемая | от 1500 | IS-01 |
| Остров 600 без рабочей зоны и без посадки | полуостров по решению | R-ISL-02 |

**Столешница острова:** D_ст = свес_раб + D_полн + t_панели + свес_посадки. Пример: 0 + 550 + 16 + 300 = 866 (свес рабочей стороны 0 — решение 19.10.2026, [01](01-grid-and-dimensions.md); панель 16; посадка 300).

**Ширина помещения под одним рядом и островом:** W_пом ≥ D_полн + a₁ + D_ост + a₂.

| Проходы | Остров 800 | Расчёт |
|---|---|---|
| 1000 / 1000 | 3350 | 550 + 1000 + 800 + 1000 |
| 1200 / 1200 | 3750 | 550 + 1200 + 800 + 1200 |

Если помещение не вмещает остров с проходами по п. 1, остров из планировки исключается, а не уменьшается проход ниже политики (R-LAY-06).

## 3. Свес и посадка (R-ISL-03)

| Параметр | Значение, мм |
|---|---|
| Свес под посадку | не менее 300 |
| Ширина на место | около 600 |
| Колени при столешнице 760 | 457 (NKBA) |
| Колени при 914 (36″) | 381 |
| Колени при 1067 (42″) | 305 |
| Барная стойка | 1050–1150 |

Число мест: floor(L/600); при свесе длиной 1800 — 3. Допустимый свес без опоры зависит от материала столешницы (ЛДСП 38, камень, компакт) — паспорт материала, источники числа не дают (D-11). Опора свеса ставится по паспорту, а не по догадке; конструкцию опоры указывает заказ (Q-10).

## 4. Конструкция (R-ISL-04)

- Остров собирается из тех же модулей ([06](06-modules.md)), но с **двумя видимыми сторонами**. Сторона посадки или прохода закрывается декоративной панелью или задней стенкой лицевого качества.
- Карту видимости кромки (K04, C11) строить заново: открытых торцов у острова нет.
- Остров крепится к полу, а не держится массой (инженерная практика; тип анкера — заказ).
- Задний зазор 50 (K01) для коммуникаций сохраняется; для острова он решает, где идут подводки — проверять по схеме инженерных систем.
- Цоколь — единый, по общему контуру; опоры и их число — по D-09.

## 5. Функции на острове (R-ISL-05)

- Компактный остров — одна активная функция (мойка **или** варка).
- Мойка и ПММ на острове напротив плиты: проверять открытые дверцы на столкновение.
- Вытяжка над варочной панелью — по документации; розетки — по схеме электрика.
- Числовых значений по этим пунктам источники не дают.

## 6. Варианты примыкания (R-ISL-06)

| Вариант | Условие | Что проверять |
|---|---|---|
| 1. Свободный остров | проходы с двух сторон | проходы п. 1; ход ящиков и дверей ряда напротив |
| 2. Полуостров | торец касается ряда | напротив торца ряд недоступен: ширина недоступной части = глубина полуострова + 2·c; заменяется глухим модулем или панелью |
| 3. Остров у пенала или стены | один проход | проход по п. 1; дверь пенала |

Пример варианта 2: корпус 550 + панель 16 + 2·2 = 570 (c = 2 — иллюстративный вход). Столешница над торцом не блокирует фасады ниже её уровня; блокирует корпус.

## 7. Алгоритм

1. Задать политику проходов (Q-06), столешницу (Q-10), способ открывания (Q-03).
2. Определить функции острова (п. 5) и посадку (п. 3).
3. Рассчитать D_ост и D_ст (п. 2); проверить W_пом.
4. Выбрать вариант примыкания (п. 6) и рассчитать недоступные участки.
5. Построить карту видимости и модульную раскладку ([10](10-layouts-and-assembly-recipes.md)).
6. Проверить ходы дверей и ящиков ряда напротив ([07](07-corner-and-junctions.md), п. 3) и список [12](12-checklists.md).

## 8. Что нужно получить

D-11 (свес по материалам), D-09 (опоры), D-17 (паспорта техники на острове), Q-06, Q-08, Q-10.
