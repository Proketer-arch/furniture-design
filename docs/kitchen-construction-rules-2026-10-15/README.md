# Правила построения, проектирования и сборки модульной кухни

Версия: 2026-10-16. Статус всех правил: **предложено** (не подтверждено владельцем заказа). База дополняет пакет AFABRIK ([K01–K19, W01–W13](../furniture-projecting-2026-10-15/instructions/01-design-base.md), [C01–C12](../furniture-projecting-2026-10-15/specifications/clarifications.md)) и ничего в нём не переопределяет.

## Для чего

Из одного набора правил собираются линейные, угловые (Г- и П-образные) кухни, кухни с островом или полуостровом, с антресолью и без неё. Правила опираются на документы производителей (Blum, Hettich, Boyard, Unihopper, GTV), норматив (ГОСТ 13025.1-85), данные поставщиков и инженерную практику. Каждое правило помечено тегом достоверности и ссылается на источник; всё, чего источники не дали, вынесено в реестр открытых данных, а не восполнено догадкой.

## Главное в десяти строках

1. **Три размерные цепи** — высота, глубина, ширина — считаются отдельно; размер корпуса и полный габарит не смешиваются ([R-DIM-01](rules-catalog.md)).
2. **Глубина:** D_полн модуля = физическая D_корп + толщина фасада; смысл исходной базы 560/575 уточняет C03, задний зазор 50 хранится отдельно ([R-DIM-02](rules-catalog.md)). Трактовку зазора подтверждает заказ; типовая столешница её не определяет. Разделять конструктивную, монтажную и видимую глубины ([15](15-project-assembly-and-acceptance.md)).
3. **Высота:** H_корп = H_рабочая (850 или 900) − опора (100/150) − столешница; «типовые 720» не принимаются без проверки.
4. **Фасад = модуль − 3** (1,5 на сторону); шов между фасадами 3; проверка по минимальному зазору петли ([R-DIM-07](rules-catalog.md)).
5. **Всё, что зависит от фурнитуры, — через «адаптер системы»**: LW, LT, NL, формулы дна и задней стенки, зазоры, нагрузки. Бренды в одном узле не смешиваются.
6. **Глубина ящика:** NL_max по LT = D_корп − занятость задней стенки; для верхнего модуля 320 с пазом (LT 300) проходят NL 270 (Blum) и 260 (Hettich Atira) — таблица в [04-drawers.md](04-drawers.md).
7. **Петли:** число по массе фасада (Blum: 2/3/4/5/6/7 при 6/12/17/22/27/32 кг, ширина ≤600) с резервом по высоте.
8. **Подъёмники:** тип по высоте корпуса, мощность по LF = KH × масса, минимальная глубина 264 (AVENTOS top) или 182 (Hettich).
9. **Углы:** слепой участок L_слеп = D_полн(соседнего ряда) + выступ ручки + 2; вылет двери d = W·sin(α − 90°).
10. **Остров:** проход не менее 1000 (рекомендовано 1100–1200), глубина не менее 800, свес под посадку не менее 300; сторона посадки — видимая, карта кромки перестраивается.

## Как пользоваться

- **Новая кухня.** Идти по 12 шагам [R-LAY-01](rules-catalog.md) (см. [10-layouts-and-assembly-recipes.md](10-layouts-and-assembly-recipes.md)), для каждого модуля заполнять карточку [R-MOD-01](rules-catalog.md).
- **Смена фурнитуры.** Заменить адаптер системы ([04-drawers.md](04-drawers.md), [03-fronts-and-hinges.md](03-fronts-and-hinges.md), [05-lifts-and-folding-fronts.md](05-lifts-and-folding-fronts.md)), пересчитать зависимые детали; габариты модулей не менять.
- **Проверка проекта.** Пройти [12-checklists.md](12-checklists.md), включая сборку и видимые стыки по [15](15-project-assembly-and-acceptance.md), и свериться с реестром [13](13-conflicts-and-open-data.md). Проверка отдельных корпусов не заменяет проверку собранной кухни, в том числе на стадии дизайна.

## Проверка базы

```bash
cd docs/kitchen-construction-rules-2026-10-15
python3 -I tools/check_rules.py        # правила, источники, ссылки, примеры расчёта, таблица NL
python3 -I tools/render_catalog.py     # пересобрать rules-catalog.md после правки rules.yaml
```

Скрипты проверяют структуру документов и арифметику примеров. Они не открывают SketchUp и не проверяют примыкания/кинематику реальной модели. Дополнение правил само по себе не изменяет плагин и ранее построенные модели.

## Границы

База не выпускает производственную документацию: присадка и УП возможны только при заданном адаптере системы и закрытых C02/C09 ([R-SUP-02](rules-catalog.md)). Неполные данные (формулы Boyard, Unihopper, GTV, Hettich AvanTech YOU, таблицы наложения петель) перечислены в [13-conflicts-and-open-data.md](13-conflicts-and-open-data.md) (22 конфликта X, 17 открытых данных D, 10 вопросов Q) с указанием документа, который их закрывает; готовность адаптеров по системам — в [11-market-and-substitutes.md](11-market-and-substitutes.md), п. 3. Цены и наличие не входят: поиск артикулов, цен и наличия у МДМ, КДМ и МАКМАРТ ведёт навык [furniture-hardware-engineering](../../skills/furniture-hardware-engineering/SKILL.md). Статус поставок Blum и Hettich в 2026 документально не подтверждён (D-13).
