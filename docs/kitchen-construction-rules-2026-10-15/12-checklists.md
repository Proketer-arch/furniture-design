# 12. Чек-листы

Проверки для согласованной стадии проекта. Фактические дефекты фиксируются в реестре замечаний проекта, пропуски — как «не проверено»; допущения и открытые параметры — в [13](13-conflicts-and-open-data.md). Каждый пункт ссылается на правило. Статусы правил в базе — «предложено»; «проверено для выпуска» присваивается только после закрытия вопросов и подтверждения документами систем (R-SUP-02).

## 0. Сборка целиком — на любой стадии модели

Подробный метод и примеры дефектов: [15](15-project-assembly-and-acceptance.md). Для каждой строки сохранять редакцию, ID объектов/узла, требование, метод, ожидаемое, фактическое, результат и вид/файл. «Не проверено» не означает положительную приёмку.

| Проверка | Критерий | Правило |
|---|---|---|
| Состав и базы | У всех объектов есть роли, ID и мировые привязки; учтены объекты вне сметы | R-ASM-01 |
| Глубины | Корпус, внешний задний зазор, фасад, облицовка и столешница увязаны; подтверждённая трактовка сохранена | R-ASM-02 |
| Фартук и пеналы | Оба внутренних стыка закрыты выбранным узлом; измерены в плане и по высоте | R-ASM-03 |
| Цоколь | Сегменты, стыки/возвраты, крепления; нет недопустимых пересечений с опорами и боковинами до пола | R-ASM-04 |
| ПММ | Чистый проём и верх не мешают установке, боковины учтены один раз, фасад/вентиляция/ход проверены | R-ASM-05 |
| Контакт и движение | Зазоры, пересечения и траектории проверены раздельно, реальные контуры подтверждены | R-ASM-06 |
| Изменения | Затронутые межмодульные проверки повторены для новой редакции | R-ASM-07 |
| Ручные исправления | Сохранены, согласованы с паспортами либо явно ограничена регенерация | R-ASM-08 |
| Доказательства | Есть измерения и виды критических стыков, включая цокольное сечение | R-ASM-09 |
| Итог | Отдельные результаты модулей, сборки, кинематики, сметы, сохранения и производства | R-ASM-10 |

## 13. Быстрые формулы

| Величина | Формула | Пример |
|---|---|---|
| LW | KB − 2·t_бок | 600 − 32 = 568 |
| LT | D_корп − k_зад | 560 − 20 = 540 |
| D_полн | D_корп + t_фасада | 560 + 19 = 579 |
| H_корп | H_раб − h_опоры − t_столешницы | 850 − 100 − 38 = 712 |
| Фасад по ширине | KB − 3 | 600 − 3 = 597 |
| Σ высот фасадов | H_корп − 3·n | 712 − 9 = 703 |
| OL | t_бок − 1,5 | 16 − 1,5 = 14,5 |
| Слепая зона | D_полн(B) + h + c | 579 + 30 + 2 = 611 |
| Ход двери | W·sin(α − 90°) | 600·sin 20° = 205,21 |
| Ширина помещения, ряд + остров | D + a₁ + D_ост + a₂ | 579 + 1000 + 800 + 1000 = 3379 |
| LF | KH × m | 868 × 7 = 6076 |
| Антресоль | потолок − верх ряда − g_т | 3000 − 2070 − 30 = 900 |
