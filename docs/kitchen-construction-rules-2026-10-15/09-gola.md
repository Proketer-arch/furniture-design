# 09. Профиль Gola (бесручечное открывание)

Правила: [R-GLA-01…07](rules-catalog.md), сопутствующие — [R-DIM-02, -03](rules-catalog.md), [R-HNG-05](rules-catalog.md), [R-LAY-02](rules-catalog.md). AFABRIK (K02) фиксирует только глубину корпуса 575 для Gola; геометрию профиля владелец не задал — она берётся у выбранного поставщика (Q-03, D-12). Все числа профиля ниже — справочные, не проектные (X-16).

## 1. Принцип

Слово «Gola» не определяет размеры: у поставщиков разные профили (L, C, верхний, вертикальные). Поэтому в модели хранится **набор параметров профиля**, который заполняется из документа выбранного поставщика, и от него считаются глубина, высоты фасадов, свес, длина реза и ограничения петли (R-GLA-01).

| Параметр профиля | Справочно из найденных источников | Источник |
|---|---|---|
| L: ширина × высота | 27 × 56…58 | Würth / Emuca (GL-01…06) |
| C: ширина × высота | 26 × 72,7…73 | то же |
| Верхний: ширина × высота | 18…20 × 38…42 | то же |
| Внутренняя глубина верхнего профиля | 19 | Emuca (GL-01) |
| Вертикальные | 27×56, 26×73, 20×20, 27×19 | GL-02…06 |
| Длины поставки | 2350 / 3900 (Emuca), 4000 (Würth), 4050 / 4100 (рынок) | |
| Вертикальные профили на пеналах | длины до 2200 | GL-10 (общий вид профильных ручек) |

Положение профилей (верхний край нижнего ряда, между ящиками, у верхнего ряда) задаётся инструкцией поставщика, источники этой базы его не фиксируют. Данных на сечение чертежами нет (D-12).

## 2. Глубина и свес

| Величина | Расчёт | Значение |
|---|---|---|
| D_корп под Gola | K02 | 575 (под обычную ручку 560, K01) |
| Разница | 575 − 560 | 15 |
| D_полн при фасаде 19 | 575 + 19 | 594 (при ручке: 579) |
| Свес столешницы 600 над фасадом | 600 − 594 | 6 |

Ориентир свеса над фасадом с Gola: 5 для прямой кромки, 10 для постформинга (GL-07, Р). При стандартной столешнице 600 свес 6 подходит только для прямой кромки; для постформинга (10) нужно изменить глубину столешницы или D_корп — решение владельца (Q-08, Q-10). Корпус «выше стандартного на 60» (пример 780) из руководства GL-08 **не принят**: противоречит R-DIM-04 и не подтверждён (X-16).

После смены глубины пересчитываются LT и NL ящиков ([04](04-drawers.md), таблица NL: колонки «Gola 575»), проход перед рядом и слепая зона угла ([07](07-corner-and-junctions.md): для Gola h_ручки = 0).

## 3. Высоты фасадов (R-GLA-02)

**Σh_фасадов = H_корп − Σ(видимые высоты профилей) − Σ(прочих зазоров).**

Зазор для пальцев между фасадами с профилем — 30–35 (30 достаточно, Р). Видимая высота профиля берётся из паспорта: для L около 57–58, для C около 73 — справочно, значения прочитаны в сессии из руководства по расчёту фасадов (GL-08, URL не сохранён), использовать только после сверки с каталогом.

Арифметика формулы (иллюстративный вход, не раскладка): H_корп 712, L = 58, C = 73, прочие зазоры 6 → Σh = 712 − 58 − 73 − 6 = 575. Для кухни без профиля — Σh = H_корп − 3·n ([03](03-fronts-and-hinges.md), R-FRN-05).

## 4. Петли и ящики с Gola (R-GLA-05)

- При горизонтальном профиле над дверью петле нужен **ограничитель угла**: Blum 86° или 92°/110° по модели; ориентир Gola — около 85° (Р, из заметок GL-08).
- Push-механизм не нужен: захват несёт профиль. Фасадный зазор определяет профиль, а не TIP-ON (Blum TIP-ON — 2,5; Hettich Push to open — 2,5–5; X-18).
- Заглубление корпуса 4 мм при типоне (K18, гипотеза AFABRIK) на Gola не переносится.
- Нулевое вхождение 155° для Gola нужно проверять отдельно: ограничитель делает открывание не более 110°/92°/86°, что снимает «полное раскрытие» (R-HNG-09).
- Для ящиков: система и NL те же ([04](04-drawers.md)); NL считается от LT при D_корп 575.

## 5. Длина реза и сопряжения (R-GLA-06)

Профиль режется по ширине модулей и непрерывен по ряду. Длина реза = ширина по фасадам + технологический припуск 2–4 (Р, из GL-08, перепроверить по инструкции профиля). Стыки в углах — торцевые заглушки или косой рез; профиль Emuca поставляется в стандартных длинах под резку (GL-02).

## 6. Ограничения (R-GLA-07)

- Не применять на радиусных и трапециевидных модулях без отдельного решения (Р) — это касается и углового решения №3 ([07](07-corner-and-junctions.md)).
- Фасады из МДФ и ЛДСП; нужна точная кромка (GL-10, K04).
- Вертикальные профили на пеналах — длины до 2200 и по высоте фасада.
- Профиль влияет на кромку, раскрой и видимость: карту кромки (K04/C11) строить с учётом профиля.

## 7. Алгоритм интеграции Gola

1. Выбрать поставщика и профиль (Q-03); получить чертёж сечения и инструкцию (D-12).
2. Занести параметры профиля: видимые высоты, внутренняя глубина, зазоры до двери и пальцев, длины поставки, припуск реза.
3. Зафиксировать D_корп = 575 и пересчитать D_полн, свес, LT, NL ([01](01-grid-and-dimensions.md), [02](02-carcass-and-assembly.md), [04](04-drawers.md)).
4. Рассчитать Σh фасадов по п. 3 для каждого модуля.
5. Для распашных фасадов выбрать петлю с ограничителем угла ([03](03-fronts-and-hinges.md)).
6. Проверить слепые зоны и ход дверей с h_ручки = 0 ([07](07-corner-and-junctions.md)).
7. Рассчитать длины резов по рядам, учесть углы и заглушки.
8. Пройти список [12](12-checklists.md).

## 8. Что нужно получить

D-12 (чертёж и размеры выбранного профиля), Q-03 (тип открывания), Q-08 (C03), Q-10 (столешница), X-16 (расхождения геометрии).
