# 11. Рынок РФ, готовность адаптеров и замены

Правила: [R-SUP-01…07](rules-catalog.md), частично [R-DRW-02…08, -15…17](rules-catalog.md), [R-HNG-12, -13](rules-catalog.md), [R-LFT-08](rules-catalog.md). Закупка, поиск артикулов, цены и наличие у МДМ, КДМ и МАКМАРТ ведутся по навыку [furniture-hardware-engineering](../../skills/furniture-hardware-engineering/SKILL.md); эта база задаёт **размерную сторону** замены, навык — коммерческую. Цен в базе нет и быть не должно.

## 1. Состояние рынка (R-SUP-04)

**Заявление владельца 19.10.2026:** вся фурнитура Blum, Hettich, Salice, Grass и Italiana Ferramenta доступна и поставляется, ограничений по выбору этих брендов нет (D-13 закрыт). В базе статус хранится как «доступно (заявление владельца)» с датой; артикул и срок уточняются у поставщика при заказе. Ниже — историческая справка на 15.10.2026, использовавшаяся до заявления.

## 4. Пример: один корпус, несколько систем

Корпус KB 600, t_бок 16 (LW 568), D_корп 560, задняя накладная (LT 560):

| Система | Дно, ширина | NL_max | Основание |
|---|---|---|---|
| Blum LEGRABOX | 568 − 35 = 533 | 550 | [04](04-drawers.md) |
| Blum TANDEMBOX antaro (ЛДСП) | 568 − 75 = 493 | 550 | [04](04-drawers.md) |
| Blum MERIVOBOX | 568 − 51 = 517 | 550 | [04](04-drawers.md) |
| Hettich ArciTech (EB 15) | 568 − 2·15 − 52,5 = 485,5 | 550 (ящик) / 500 (внутренний, Δ = 12) | [04](04-drawers.md) |
| Hettich InnoTech Atira (EB 12,5) | 568 − 2·12,5 − 51,5 = 491,5 | 520 | [04](04-drawers.md) |
| Grass Nova Pro Scala (EB 29) | 568 − 2·29 = 510 | 550 | [04](04-drawers.md) |

Ширина дна в этом примере лежит в пределах 485,5…533 (разброс 47,5) — следствие толщины боковины и конструкции; формулы между брендами не переносятся, замена бренда = замена адаптера и пересчёт зависимых деталей (R-SUP-01, [10](10-layouts-and-assembly-recipes.md), п. 10).

## 5. Проверка аналога (матрица)

Аналог допустим как прямая замена, только если совпадают все обязательные параметры; различие в одном — новый проектный вариант с пересчётом.

| Параметр | Что сравнить |
|---|---|
| Геометрия | Δ_сист, высоты, EB, формулы дна и задней, наложение, TB, глубина |
| Нагрузка и условия | класс, динамическая нагрузка, масса фасада, диапазоны LF |
| Присадка | рисунок отверстий, шаг, высота планки |
| Комплект | замки, ограничители, синхронизация, планки |
| Управление | push / TIP-ON / демпфер, зазор фасада (X-18) |
| Регулировка | диапазоны по трём осям |
| Ресурс | по документу, не по маркетингу (X-22) |
| Цена и наличие | поставщик, регион, дата — по навыку закупки |

## 6. Стратегия при неопределённых поставках

1. Для каждого узла назначить основной и запасной адаптер (минимум две системы разных производителей).
2. Закладывать геометрию корпуса так, чтобы запасная система проходила по LW, LT и высоте (проверять по [04](04-drawers.md), таблица NL).
3. Не смешивать бренды в одном узле: ящик + направляющая, петля + планка, подъёмник + фасад (R-SUP-01). Разные бренды в разных узлах допустимы.
4. Хранить редакцию и дату документа системы (R-SUP-06).
5. Для систем с данными «низкая» запрашивать у поставщика планировочный лист или делать опытный образец до серии (R-SUP-03).
6. Решения по рынку фиксировать в реестре ([13](13-conflicts-and-open-data.md)); статус поставок — заявление владельца от 19.10.2026 (R-SUP-04, D-13 закрыт).

## 7. Что запросить у поставщика на каждую систему (R-SUP-06)

| Узел | Документы |
|---|---|
| Ящики | планировочный лист: LT/NL, дно, задняя, EB, присадка, синхронизация |
| Петли | таблицы наложения, TB, зазоров; число по массе и высоте |
| Подъёмники | таблицы LF и массы, присадка, мин. глубина |
| Профиль | чертёж сечения, инструкция, длины |

## 8. Ресурс (R-SUP-07)

Значения ресурса в циклах (Blum до 200 000, Hettich до 160 000, Boyard EVO 100 000, Unihopper скрытые 60 000) получены по разным методикам; в блоге 2026 года Blum и Hettich указаны «от 80 000», Boyard — 40 000–60 000 (X-22). Для расчётов не использовать.
