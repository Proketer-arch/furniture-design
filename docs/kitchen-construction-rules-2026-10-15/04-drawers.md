# 04. Ящики: адаптеры систем, формулы, глубина, верхние ящики

Правила: [R-DRW-01…17](rules-catalog.md), [R-CAR-02, -03](rules-catalog.md), для Gola — [R-GLA-03](rules-catalog.md). Все размеры ящика выводятся из внутренних размеров корпуса, которые считаются в [02](02-carcass-and-assembly.md). Цифры систем прочитаны по документам производителей 19.10.2026 (источники — [14](14-sources.md)); поставка Blum, Hettich, Salice, Grass и Italiana Ferramenta подтверждена владельцем (R-SUP-04), поэтому все эти системы допускаются в выпуск.

## 1. Термины

| Обозначение | Смысл |
|---|---|
| KB | ширина корпуса |
| LW (LB у Hettich, LWK у Grass) | внутренняя ширина = KB − 2·t_бок |
| LT | внутренняя глубина = D_корп − k_зад (R-CAR-02) |
| NL | номинальная длина направляющей |
| LT_min (MET у Grass) | минимальная внутренняя глубина корпуса по документу системы |
| Δ_сист | LT_min − NL |
| EB | монтажная ширина (системы с двойной боковиной) |
| BB, BL, RB | ширина дна, длина дна, ширина задней стенки (обозначения Hettich и Grass) |
| δ_G | вычет профиля Gola из внутренней глубины = 27 (R-GLA-03) |

**Принцип:** формулы фурнитуры в проекте не зашиваются; модуль задаёт KB, t_бок, D_корп и тип задней стенки, а ящик берётся из адаптера (R-DRW-01). Бренды в одном узле не смешиваются; нет адаптера — нет присадки и раскроя дна.

## 3. Максимальный NL по глубине корпуса

NL_max — наибольшая стандартная длина системы, для которой LT_min(NL) ≤ LT (R-CAR-03). Для Gola из LT вычитается δ_G = 27 (R-GLA-03). Таблица рассчитана скриптом `tools/check_rules.py` (при расхождении с расчётом проверка падает); значения Atira берутся из каталожной таблицы LT_min выше (без Push to open). Ряды NL у MERIVOBOX, Grass и Unihopper внутри диапазона приняты стандартными — перед выпуском сверить с таблицей производителя.

Выводы:

- Нижний модуль 560: Blum, Grass, Unihopper и ArciTech (обычный ящик) дают NL 550 при накладной задней стенке и 500 при стенке в пазу; Atira — 520 в обоих случаях. Внутренний ящик ArciTech и Grass — 500.
- Под Gola (GOL) NL 500 доступен всем перечисленным системам, кроме Atira (470): при внутренней глубине 544 (решение 18.10: отступ задней стенки 12 + паз 4) NL_max = 544 − 27 − 3 = 514, то есть та же NL 500. ArciTech с Push to open Silent при пазовой задней стенке — NL 450 (нужно 521 при доступных 513).
- В верхнем модуле 320 с задней стенкой в пазу (LT 300) проходят NL 270 (Blum, Hettich ArciTech, Grass, Unihopper) и 260 (Atira, только без Push to open); NL 300 у Atira (нужно 315) — только при накладной задней стенке и только для ящика, внутренний ящик Atira NL 300 (324) не помещается и при накладной.
- Для Boyard START, GTV и Makmart SC Δ_сист не найден — в таблицу они не входят (D-04, D-05, D-19). Boyard DB9891 имеет ряд 400–500 и в верхний модуль не помещается.

## 4. Минимальная ширина модуля с ящиками (R-DRW-09)

KB_min = LW_min + 2·t_бок: LEGRABOX 245 (однодетальная синхронизация) → 277 при боковинах 16; 294 (тяга) → 326; TANDEMBOX 238 → 270; Atira по ряду KB — 275. Модуль 300 при боковинах 16 имеет LW 268. Для остальных систем LW_min брать из адаптера; в модели без значения ящик не включается.

## 5. Нагрузка, TIP-ON, синхронизация (R-DRW-10, R-DRW-14)

- Класс нагрузки — по массе содержимого с запасом; LEGRABOX 70 кг — при NL ≥ 450.
- TIP-ON BLUMOTION: S0 < 10 кг (NL 270–300); S1 10–20 кг (270–300); L1 до 20 кг (350–600); L3 15–40 кг (350–600); L5 35–70 кг (450–650).
- Широкий ящик (KB ≥ 750) — синхронизация и стабилизатор по документу системы; TANDEMBOX при KB ≥ 750 — фиксатор вала и уголок-держатель дна.

## 6. Внутренние ящики и ящик под мойку (R-DRW-11, R-DRW-12)

- Внутренний ящик за дверью: LEGRABOX и MERIVOBOX — передняя LW − 126 (LEGRABOX: стекло LW − 80, галерея LW − 90); TANDEMBOX — LW − 132 (LW − 122 с релингом); Atira — PL = LB − 2·EB − 57,6. Дверь — 155° с нулевым вхождением ([03](03-fronts-and-hinges.md), R-HNG-09).
- Ящик под мойку: LEGRABOX — ход выреза Y 115–155; TANDEMBOX — NL наружного − NL внутреннего ≥ 150, ширина выреза = разница − 10, Y: TIP-ON не менее 75, BLUMOTION не менее 48, не более 225.

## 7. Ящики верхних модулей и антресоли (R-DRW-13)

Глубина верхнего модуля 320 даёт LT 300 при задней стенке в пазу и 320 при накладной. Допустимые NL — по таблице выше: 270 для Blum, ArciTech, Grass, Unihopper (LT ≥ 273 / 275), 260 для Atira (279 / 288; с Push to open 304 / 314 при LT 300 не проходит). Часто используемое содержимое — не выше 1250 над полом (верх передней стенки ящика, ГОСТ); выше — редкое. Классы нагрузки — 25–40 кг.

## 8. Раскладка ящиков по высоте (R-FRN-05, R-MOD-03)

- Без профиля: Σh_i = H_корп − 3·n. При H_корп 740 (HND) три ящика дают 731, два — 734; при 760 — 751 и 754. Каждая высота не меньше минимальной для боковины системы.
- С Gola (GOL): S(n) = H_корп − 58 − 73·(n − 1) − 3, не более 3 фасадов (R-GLA-02): при H_корп 760 — 699 / 626 / 553 для 1 / 2 / 3 фасадов. Размеры ящиков и NL — по таблице выше с вычетом δ_G.
