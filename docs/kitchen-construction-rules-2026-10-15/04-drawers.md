# 04. Ящики: адаптеры систем, формулы, глубина, верхние ящики

Правила: [R-DRW-01…14](rules-catalog.md), [R-CAR-02, -03](rules-catalog.md). Здесь все размеры ящика выводятся из внутренних размеров корпуса, которые считаются в [02](02-carcass-and-assembly.md).

## 1. Термины

| Обозначение | Смысл |
|---|---|
| KB | ширина корпуса |
| LW (LB у Hettich) | внутренняя ширина = KB − 2·t_бок |
| LT | внутренняя глубина = D_корп − k_зад |
| NL | номинальная длина направляющей |
| Δ_сист | LT_min − NL по документу системы |
| EB | монтажная ширина (системы с двойной боковиной) |

**Принцип:** формулы фурнитуры в проекте не зашиваются; модуль задаёт KB, t_бок, D_корп и тип задней стенки, а ящик берётся из адаптера (R-DRW-01).

NL_max — наибольшая стандартная длина системы, для которой NL + Δ_сист ≤ LT (R-CAR-03). Таблица рассчитана скриптом `tools/check_rules.py` (при расхождении с расчётом проверка падает).

Выводы:

- В нижнем модуле 560 любая из систем даёт NL 500–550 (Atira 520); паз сокращает NL на 0–50.
- Под Gola (575) NL 550 доступен Blum при накладной и при пазовой задней стенке.
- В верхнем модуле 320 с задней стенкой в пазу (LT 300) проходят NL 270 (Blum) и 260 (Atira); NL 300 у Atira (нужно 315) — только с накладной задней стенкой.
- Для Unihopper, Boyard, GTV значения Δ_сист не найдены — таблица их не содержит (D-02, D-04, D-05).

## 4. Минимальная ширина модуля с ящиками (R-DRW-09)

KB_min = LW_min + 2·t_бок: LEGRABOX 245 (однодетальная синхронизация) → 277 при боковинах 16; 294 (тяга) → 326; TANDEMBOX 238 → 270; Atira по ряду KB — 275. Модуль 300 при боковинах 16 имеет LW 268.

## 5. Нагрузка, TIP-ON, синхронизация (R-DRW-10, R-DRW-14)

- Класс нагрузки — по массе содержимого с запасом; LEGRABOX 70 кг — при NL ≥ 450.
- TIP-ON BLUMOTION: S0 < 10 кг (NL 270–300); S1 10–20 кг (270–300); L1 до 20 кг (350–600); L3 15–40 кг (350–600); L5 35–70 кг (450–650).
- Широкий ящик (KB ≥ 750) — синхронизация и стабилизатор по документу системы; TANDEMBOX при KB ≥ 750 — фиксатор вала и уголок-держатель дна.

## 6. Внутренние ящики и ящик под мойку (R-DRW-11, R-DRW-12)

- Внутренний ящик за дверью: LEGRABOX — передняя LW − 126 (стекло LW − 80, галерея LW − 90); TANDEMBOX — LW − 132 (LW − 122 с релингом). Дверь — 155° с нулевым вхождением.
- Ящик под мойку: LEGRABOX — ход выреза Y 115–155; TANDEMBOX — NL наружного − NL внутреннего ≥ 150, ширина выреза = разница − 10, Y: TIP-ON не менее 75, BLUMOTION не менее 48, не более 225.

## 7. Ящики верхних модулей и антресоли (R-DRW-13)

Глубина верхнего модуля 320 даёт LT 300 при задней стенке в пазу и 320 при накладной. Допустимые NL — по таблице выше. Часто используемое содержимое — не выше 1250 над полом (верх передней стенки ящика, ГОСТ); выше — редкое. Классы нагрузки — 25–40 кг.

## 8. Раскладка ящиков по высоте (R-FRN-05, R-MOD-03)

Σh_i = H_корп − 3·n. Пример: корпус 712, три ящика — 703 суммарно; корпус 712, два ящика — 706. Каждая высота не меньше минимальной для боковины системы.
