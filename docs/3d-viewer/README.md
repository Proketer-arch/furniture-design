# 3D-просмотрщик кухонь AFABRIK — инструкция

## Что это

Страница в браузере, где клиент видит свою кухню в 3D: вращает модель, открывает двери и ящики, меняет декоры
фасадов, переключает «день / вечер» и подсветку. Работает на компьютере и телефоне, ничего устанавливать не нужно.
Каждая кухня — отдельная ссылка вида:

    https://3d.afabrik.ru/v/<код>/

Код ссылки случайный (например `2d12dd5ee5514250`): подобрать чужую ссылку нельзя, поисковики страницы не индексируют.
Ссылку можно отправить клиенту в мессенджер или вставить на сайт (в Тильде — блок T123, код ниже).

## Что умеет клиент

| Действие | Как |
|---|---|
| Вращать, приближать | мышь / палец; колесо или щипок — приближение |
| Открыть одну дверь/ящик | нажать на фасад (ещё раз — закрыть) |
| Открыть / закрыть всё | кнопки «Открыть» / «Закрыть» |
| Ракурсы | «Общий вид», «Спереди», «Слева», «Справа», «Сверху» |
| Сменить декор | ряды «Дерево» и «Цвет»: дерево меняется на дерево, однотон — на однотон |
| Свет | переключатель «День / Вечер», кнопка «Подсветка», температура 2700 / 3000 / 4000 / 5000 K |
| Дочистка картинки | автоматически: когда кухня не двигается, за ~0,5–1 с края выравниваются, тени от окна становятся мягкими. Без зерна, ничего нажимать не нужно |

## Как подготовить новую кухню

1. Спроектировать кухню в SketchUp.
2. Попросить Claude (чат со SketchUp) собрать папку `~/Downloads/viewer-<клиент>/` по заданию ниже.
3. Написать Claude, который ведёт просмотрщик: «папка viewer-<клиент> готова». Он сам:
   подготовит текстуры декоров из библиотеки Egger/Kronospan, выложит модель на сервер, проверит на компьютере
   и телефоне и пришлёт ссылку.
4. Через 1–2 минуты после выкладки сервер сам «запекает» мягкие тени — модель на той же ссылке становится
   качественнее. Ничего делать не нужно.

### Состав папки `viewer-<клиент>/`

| Файл | Что это |
|---|---|
| `model.skp` | кухня отдельным файлом, мм, всё **закрыто** |
| `model.glb` | экспорт SketchUp 2025 → GLB, всё закрыто |
| `animation.json` | что и как открывается (формат ниже) |
| `animation.md` | то же таблицей для человека |
| `decors.md` | какие декоры может выбирать клиент |

Требования к модели:
- каждая дверь, ящик, подъёмник — отдельный компонент/группа с **уникальным понятным** именем;
- у дверей и подъёмников начало (ось) компонента — на оси петли;
- материалы фасадов названы кодом декора: «Egger H1385 ST40 Дуб Каселла натуральный»; один декор — один материал;
- стены, пол, потолок, люди, растения — удалить; текстуры ≤ 2048 px; GLB желательно < 30 МБ.

### Формат `animation.json` (мм и градусы, оси SketchUp, Z вверх)

```json
{
  "items": [
    {"name": "Дверь Н04 левая — петли у угла", "type": "door",   "axis": "z", "value": 90,   "pivot": [5700, 8772, 0]},
    {"name": "Дверь ПММ — откидывается вниз",    "type": "flap",   "axis": "x", "value": -85,  "pivot": [4642, 8290, 105]},
    {"name": "Ящик 1 Н06",                       "type": "drawer", "axis": "x", "value": -450, "pivot": [0, 0, 0]}
  ],
  "views": [
    {"name": "Active View", "position": [X, Y, Z], "target": [X, Y, Z]},
    {"name": "Спереди",     "position": [X, Y, Z], "target": [X, Y, Z]}
  ],
  "facade_materials": ["точные имена материалов фасадов"]
}
```
- `door` — распашная; `flap` — откидная/подъёмная; `drawer` — ящик (ход в мм со знаком).
- `value` для двери — угол в градусах (+ против часовой при взгляде с плюса оси), `pivot` — точка на оси петли, мм.
- `views` — камеры в мм; «Active View» — стартовый вид 3/4, «Спереди» — строго напротив кухни.

### `decors.md` — пример

```
Дерево — материал «Egger H1385 ST40 Дуб Каселла натуральный»; исходный H1385 ST40;
  варианты: H1386 ST40 Дуб Каселла коричневый; H3317 ST28 Дуб Кунео коричневый; H1145 ST10 Дуб Бардолино натуральный
Цвет — материал «Egger U702 ST9 Кашемир серый»; исходный U702 ST9;
  варианты: U104 ST9 Алебастр белый; U640 TM Зелёный оливковый; AU-U311 ST9 Бургундский красный
```
Оптимально 3–5 вариантов дерева и 4–5 цвета: больше — панель разрастается на телефоне.

## Как вставить на сайт (Тильда, блок T123)

```html
<div style="position:relative;width:100%;height:80vh;min-height:520px">
  <iframe src="https://3d.afabrik.ru/v/<код>/" style="position:absolute;inset:0;width:100%;height:100%;border:0"
          allow="fullscreen" loading="lazy" title="3D-модель кухни"></iframe>
</div>
```

## Срок жизни и закрытие ссылки

- Ссылка работает бессрочно — пока лежит папка проекта на сервере.
- Закрыть ссылку: Claude удаляет папку `/opt/kitchen-viewer/dist/v/<код>/` на сервере — ссылка сразу отдаёт «не найдено».
  Остальные кухни работают. Вернуть — положить папку обратно (тот же код = та же ссылка).

## Как это устроено (для техподдержки)

- **Сервер:** Timeweb Cloud, 200.165.229.108 (Docker + Coolify + Traefik). Адрес `3d.afabrik.ru` — поддомен в
  Timeweb Cloud → Домены → afabrik.ru → Поддомены (A 200.165.229.108). Старый адрес `view.200.165.229.108.sslip.io` работает параллельно.
- **Папка на сервере:** `/opt/kitchen-viewer` — `docker-compose.yml`, `nginx.conf`, `.env`, `dist/` (программа),
  `dist/v/<код>/` (данные кухни), `baker/` (запекание).
- **Контейнеры:**
  - `kitchen-viewer` — nginx, отдаёт страницу и файлы моделей (128 МБ памяти, 0.5 ядра);
  - `kitchen-baker` — фоновое запекание теней: без сети, до 2 ядер с низким приоритетом, 3 ГБ памяти.
- **Данные одной кухни** (`dist/v/<код>/`): `kitchen.glb` (модель), `animation.json` (двери/ящики/виды),
  `decors.json` + `decors/*.webp` (декоры), `palette.json`, `kitchen.baked.glb` + `bake.json` (создаёт сервер сам).
- **Программа:** three.js (WebGL). Картинка считается на устройстве клиента, не на сервере.
  - постобработка: затенение углов (N8AO), сглаживание (SMAA), свечение подсветки вечером, тон-маппинг Neutral;
  - освещение: нейтральная студийная HDRI (Poly Haven, CC0) + солнце с тенями, стена и пол; вечером — лента под
    верхними шкафами, подсветка цоколя, споты над варочной и мойкой;
  - дочистка на паузе: среднее 48 обычных кадров (на телефоне 16) со сдвигом камеры внутри пикселя и «размытым» солнцем — идеальные края и мягкая полутень без шума;
  - запекание: свой скрипт (развёртка второго UV, лучи по BVH, запись в GLB через gltf-transform) — ~1 мин на кухню.
- **Отладка по адресу:** `?rf=0` — без дочистки на паузе, `?fx=0` — без постобработки, `?baked=0` — без запечённых теней.
- **Исходный код:** проект `kitchen-viewer` (vite + three.js + тесты vitest/pytest/playwright). Выкладка:
  `npm run build:deploy` → содержимое `dist-deploy/` в `/opt/kitchen-viewer/dist/` (папку `v/` не трогать).
- **Журналы:** `docker logs kitchen-baker` (запекание), `docker logs kitchen-viewer`.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Клиент видит старую версию | обновить страницу (на Mac Cmd+Shift+R, на телефоне закрыть и открыть вкладку) |
| Модель без мягких теней | запекание ещё идёт (1–2 мин) или упало — смотреть `bake.json` в папке кухни |
| Дверь не открывается | имя в `animation.json` не совпадает с именем группы в модели |
| Декор не меняется | имя материала в `decors.json` не совпадает с моделью |
| Тормозит на старом телефоне | вечер с подсветкой — самый тяжёлый режим; днём легче |
