Документы «Командора» закрыты (403).
- Общие с кухней решения: фасад = модуль − 3; корпус всегда ЛДСП 16; задние стенки ХДФ 4 в паз (k_зад 20), ЛДСП 8–9 в четверть (8–9), ЛДСП 16 между боковинами (16, не подтверждено); накладная ХДФ не применяется; глубина корпуса по боковине (уточнения владельца 23.11.2026, как в PR furniture-design#2).
- Ключевые числа: внутри под плечики ≥ 560 (ГОСТ) → распашной корпус 580; купе: двери занимают около 100, при 650 внутри 530; длинная одежда ≥ 1400, короткая ≥ 900, штанга ≤ 1900; полка ЛДСП 16 при прогибе ≤ 5 мм на метр — бельё 800, книги 600; петли — большее из «по высоте» (900/1600/2000/2400 → 2/3/4/5) и «по массе» Blum; купе H:W ≤ 4 (лучше 3); подъём лёжа sqrt(H² + D²) ≤ потолок − 30.
- Вопросы владельцу Q-01…Q-09: ЛДСП 16 задник, глубина распашного (580) и купе (650 против ГОСТ 680), полки длиннее 800, крепление к стене (> 1600), пролёт штанги 1000, выпрямитель с 2000, основная система купе, антресоль при высоте > 2400.
