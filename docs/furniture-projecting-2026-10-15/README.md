# Проектирование мебели: навыки, инструкции и ТЗ

Подготовлено 15 октября 2026 года по пяти DOCX пользователя. Пакет содержит исходные тексты в Markdown, базу требований, рабочие инструкции, два заполняемых ТЗ и два самостоятельных навыка Codex. Это подготовка материалов для последующей работы; ТЗ конкретного заказа ещё не заполнены.

## Начать работу

1. Выбрать [ТЗ кухни](specifications/kitchen-brief.md) или [ТЗ шкафа](specifications/wardrobe-brief.md), сделать копию для заказа и заполнить известное.
2. Прочитать соответствующую [инструкцию кухни](instructions/02-kitchen-workflow.md) или [инструкцию шкафа](instructions/03-wardrobe-workflow.md).
3. Использовать [базу требований](instructions/01-design-base.md), сохраняя область применения размеров и материалов.
4. Проверить применимые [вопросы C01–C12](specifications/clarifications.md) и записать решения с основанием.
5. Передать результат по порученной стадии согласно [контролю проверки и передачи](instructions/04-review-and-handoff.md).

## Навыки Codex

| Навык | Назначение | Файл |
|---|---|---|
| `$afabrik-kitchen-projecting` | Бриф, конструктивные параметры, планировка и контроль кухни по S1/S2/S5 | [SKILL.md](skills/afabrik-kitchen-projecting/SKILL.md) |
| `$afabrik-wardrobe-projecting` | Обмер, корпус, двери, основание и наполнение шкафа по S3/S4 | [SKILL.md](skills/afabrik-wardrobe-projecting/SKILL.md) |

Копии навыков установлены в стандартную папку пользователя `~/.codex/skills/` с сохранением всего содержимого каждой папки. Если текущий чат ещё не показывает новые навыки, открыть новый чат после обновления списка навыков приложения. Наличие файлов и структурная проверка не подтверждают доступ к БАЗИС/SketchUp или результат реального моделирования.

Пример для кухни:

```text
Используй $afabrik-kitchen-projecting. Подготовь ТЗ и дизайн кухни в SketchUp по приложенным обмерам. Сейчас нужны модель и виды. Чертежи пока не требуются. Применяй базу S1/S2/S5, отмечай допущения, уточни влияющие на геометрию вопросы.
```

Пример для шкафа:

```text
Используй $afabrik-wardrobe-projecting. По фото и обмеру заполни ТЗ шкафа, предложи двери и наполнение, затем подготовь модель в доступной программе. Спорные толщины и опоры сначала вынеси на уточнение.
```

Для переноса скопировать целиком нужную папку из `skills/` в папку навыков другой установки Codex. Каждый навык содержит собственный шаблон ТЗ и ссылки только на собственные ресурсы. Другие установленные мебельные навыки не заменены.
