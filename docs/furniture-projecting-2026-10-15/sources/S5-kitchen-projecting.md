<a id="s5-p020"></a>

**S5-P020**

Зона хранения: количество и тип шкафов (навесные, напольные, высокие пеналы), выдвижные системы, корзины, карусели.

<a id="s5-p021"></a>

**S5-P021**

<a id="s5-p022"></a>

**S5-P022**

Зона приготовления пищи: тип плиты (газовая, электрическая, индукционная), необходимость вытяжки.

<a id="s5-p023"></a>

**S5-P023**

Зона мойки: тип мойки (врезная, накладная, интегрированная), смеситель, измельчитель отходов.

**S5-P024**

<a id="s5-p026"></a>

**S5-P026**
