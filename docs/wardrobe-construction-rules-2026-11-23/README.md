# Правила проектирования корпусных шкафов — распашных и купе

Версия: 2026-11-23. Статус всех правил: **предложено** (подтверждаются на заказе). База добавляет числа к пакету AFABRIK для шкафа ([W01–W13](../furniture-projecting-2026-10-15/instructions/01-design-base.md), [инструкция](../furniture-projecting-2026-10-15/instructions/03-wardrobe-workflow.md), [ТЗ](../furniture-projecting-2026-10-15/specifications/wardrobe-brief.md)) и сам пакет не меняет. Метод тот же, что у [базы кухни](../kitchen-construction-rules-2026-10-15/README.md): теги достоверности Н/П/И/Р/?, адаптер системы, реестр конфликтов и вопросов, машиночитаемый `rules.yaml` с проверкой.

Источники: ГОСТ 13025.1-85, ГОСТ 16371-2014, ГОСТ 19882-91 (полные тексты), каталоги Aristo 2020 и Raumplus S1200, данные петель Blum, Hettich и Ferrari (МДМ), пантографы Hettich и Häfele, форумы мебельщиков и статьи фабрик. Числа без источника не вносились: они в [реестре](07-conflicts-and-questions.md).

## Главное в десяти строках

1. **Глубина корпуса — по боковине**, задняя стенка вычитается из внутренней: ХДФ в паз −20, ЛДСП 8–9 в четверть −8/9, ЛДСП 16 −16; накладная ХДФ не применяется (RW-DIM-01).
2. **Распашной шкаф:** для плечиков по ГОСТ нужно 560 внутри → корпус 580, с фасадом около 600 (RW-DIM-02).
3. **Купе:** двери занимают около 100 глубины; при 650 внутри 530, при 600 — 480, по ГОСТ нужно 680 — решает владелец (RW-DIM-03, Q-03).
4. **Высота:** шкаф, поднимаемый из положения лёжа, проходит, если sqrt(H² + D²) ≤ потолок − 30 (RW-DIM-05); выше — антресоль отдельным корпусом (RW-ANT-02).
5. **Зоны по ГОСТ:** длинная одежда ≥ 1400 (практика 1500–1700), короткая ≥ 900, штанга до полки ≥ 50, верх штанги ≤ 1900, выше — пантограф (RW-INT-01…RW-INT-04).
6. **Полки ЛДСП 16** (прогиб ≤ 5 мм на метр по ГОСТ): под бельё до 800, под книги до 600, под лёгкие вещи до 1150 (RW-SHF-03).
7. **Штанга без опоры** — до 1000 (RW-INT-06, Q-06); пантограф — по диапазону ширины модели (RW-INT-05).
8. **Распашные двери:** модуль − 3; петли — большее из «по высоте» (до 900 — 2, до 1600 — 3, до 2000 — 4, до 2400 — 5) и «по массе» Blum (RW-SWG-02, RW-SWG-03).
9. **Купе:** высота H_проёма − 40…45, ширина (L + k·p)/n по системе; H : W створки ≤ 4, лучше ≤ 3 (RW-SLD-02…RW-SLD-04).
10. **Установка:** запас в нише 30 по высоте и 50 по ширине; крепить к стене шкафы выше 1600 (RW-INS-05, RW-INS-01, Q-05).

## Проверка базы

```bash
cd docs/wardrobe-construction-rules-2026-11-23
python3 -I tools/check_rules.py          # правила, источники, ссылки, расчёты, таблицы
python3 -I tools/render_catalog.py       # пересобрать rules-catalog.md после правки rules.yaml
```

Нужен PyYAML. Скрипт также проверяет, что упомянутые правила кухни (R-…) существуют в соседней базе кухни. Проверка документов и арифметики не подтверждает реальную сборку и не открывает модель.

## Границы

Цены, артикулы и наличие не входят. Производственная документация по купе — только после выбора системы (Q-08) и её адаптера; по полкам и штангам — с учётом открытых данных D-02, D-03. Правила с тегами **Р** и **?** не основание для выпуска в производство.
